# RVUNL / डिस्कॉम ट्रैकर

RVUNL और डिस्कॉम (JVVNL, AVVNL, JdVVNL) की **जूनियर असिस्टेंट / कमर्शियल असिस्टेंट-II** भर्ती परीक्षा की तैयारी के लिए अध्ययन ट्रैकर ऐप। यह वेब ऐप है और Capacitor से Android APK भी बनता है।

- ऐप का नाम: RVUNL/DISCOM Tracker
- Android ऐप ID: `com.rvunldiscom.jatracker` (APK इंस्टॉल होने के बाद इसे न बदलें, वरना ऐप अलग ऐप मानी जाएगी)

## ऐप में क्या-क्या है

| सुविधा | विवरण |
|---|---|
| सिलेबस ट्रैकर | विषय, यूनिट और टॉपिक के हिसाब से प्रगति। टॉपिक को पूरा, बुकमार्क या रिवीजन के लिए चिह्नित कर सकते हैं। |
| अध्ययन सामग्री | टॉपिक के मुख्य बिंदु और विस्तृत लेख। एक बार सिंक होने के बाद ऑफलाइन भी दिखते हैं। |
| MCQ टेस्ट | हर टॉपिक पर अभ्यास प्रश्न। गलत उत्तर "गलत उत्तर बैंक" में जमा होते हैं। |
| मॉक टेस्ट | पूरे सिलेबस से रैंडम प्रश्न (25 / 50 / 100)। **Pre** में नेगेटिव मार्किंग नहीं, **Main** में नेगेटिव मार्किंग। |
| रिवीजन | स्पेस्ड रिपीटिशन से तय होता है कि कौन सा टॉपिक कब दोहराना है। |
| कमज़ोर टॉपिक | MCQ में कम अंक वाले टॉपिक अपने-आप पहचाने जाते हैं। |
| फ्लैशकार्ड | याद करने के लिए कार्ड। |
| टाइपिंग टेस्ट | Phase-II टाइपिंग की तैयारी, कीबोर्ड और उंगलियों की गाइड के साथ। |
| टाइमटेबल और अलार्म | रोज़ का समय-सारणी और अलार्म। |
| आज और शेड्यूल | रोज़ का लक्ष्य, स्ट्रीक और अध्ययन हीटमैप। |
| आँकड़े | तैयारी का स्कोर, प्रगति और मॉक टेस्ट का इतिहास। |
| परीक्षा की तारीख | सेटिंग में तारीख डालने पर होम स्क्रीन पर बचे हुए दिन दिखते हैं और रोज़ के रिमाइंडर में लक्ष्य जुड़ता है। |
| खोज, नोट्स, डाउट | टॉपिक खोजना, अपने नोट्स और डाउट लिखना। |
| बैकअप और रीस्टोर | सेटिंग से पूरा डेटा फ़ाइल में सेव और वापस लोड कर सकते हैं। |

सारा प्रगति डेटा फोन/ब्राउज़र के IndexedDB में रहता है, इसलिए ऐप बिना इंटरनेट के भी चलता है।

## परीक्षा की जानकारी

स्रोत: RVUN का आधिकारिक विज्ञापन क्रमांक RVUN/Rectt.-2026-27/03, दिनांक 04 अगस्त 2026।

- Phase-I के **दो चरण** होते हैं:
  - **Pre-examination**: सिर्फ छंटनी के लिए, इसके अंक अंतिम मेरिट में नहीं जुड़ते। नेगेटिव मार्किंग नहीं।
  - **Main-examination**: इसके अंक अंतिम मेरिट में **40%** जुड़ते हैं। नेगेटिव मार्किंग है।
- **Phase-II (टाइपिंग टेस्ट)**: अंतिम मेरिट में **60%**।
- कुल 140 प्रश्न, 200 अंक, 2 घंटे। कोई इंटरव्यू नहीं।
- विषय: रीजनिंग, गणित (10वीं स्तर), सामान्य ज्ञान और दैनिक विज्ञान (राजस्थान पर विशेष बल), सामान्य हिंदी, सामान्य अंग्रेज़ी।
- न्यूनतम पासिंग अंक: सामान्य (UR) 30%, आरक्षित वर्ग 20%।

**जिन बातों की पुष्टि नहीं है:**
- Main परीक्षा में नेगेटिव मार्किंग का सही अनुपात नोटिफिकेशन में नहीं दिया गया। ऐप में अभी **0.25** मान रखा है। पुष्टि होने पर `src/lib/syllabus/examScheme.ts` में `NEGATIVE_MARKING_BY_MODE` बदलें।
- विषय-wise अंकों का बँटवारा (जैसे राजस्थान GK के 45 प्रश्न) एक तीसरे पक्ष की साइट से लिया गया है, आधिकारिक नोटिफिकेशन से नहीं। इसे अनुमान मानें।

## Supabase सेटअप (अध्ययन सामग्री और MCQ के लिए)

ऐप के MCQ और अध्ययन सामग्री Supabase से आते हैं। **इस ऐप के लिए नया Supabase प्रोजेक्ट बनाएँ।** किसी दूसरे ऐप का प्रोजेक्ट दोबारा इस्तेमाल न करें, क्योंकि सिंक पूरी तालिका एक साथ डाउनलोड करता है और परीक्षा के हिसाब से कोई फ़िल्टर नहीं है।

1. [supabase.com](https://supabase.com) पर नया प्रोजेक्ट बनाएँ।
2. SQL Editor में `SETUP-INSTRUCTIONS.md` में दी गई SQL चलाएँ। इससे `mcq_questions` और `topic_content` तालिकाएँ और पढ़ने की नीति (RLS) बन जाती हैं।
3. प्रोजेक्ट की Settings > API से `Project URL` और `anon public` कुंजी लें।
4. प्रोजेक्ट की जड़ में `.env` फ़ाइल बनाकर ये दो पंक्तियाँ डालें:

```
VITE_SUPABASE_URL=https://आपका-प्रोजेक्ट.supabase.co
VITE_SUPABASE_ANON_KEY=आपकी-anon-कुंजी
```

5. तालिकाओं में `topic_id` वही रखें जो `src/lib/syllabus/syllabusData.ts` में हैं, तभी सामग्री सही टॉपिक से जुड़ेगी।

`.env` को कभी GitHub पर न डालें। इसे `.gitignore` में जोड़ दिया गया है।

## Android APK बनाना

`.github/workflows/build-apk.yml` मुख्य (`main`) शाखा पर हर push के बाद APK बनाकर GitHub Releases में डालता है। हाथ से चलाने के लिए Actions टैब से `build-apk` चुनें।

> **सुरक्षा चेतावनी:** अभी साइनिंग keystore (`keystore.b64`) और उसका पासवर्ड रिपॉज़िटरी में ही हैं। जिसके पास रिपॉज़िटरी की पहुँच है, वह आपके नाम से APK साइन कर सकता है।
> - रिपॉज़िटरी को **Private** रखें।
> - बेहतर तरीका: नया keystore बनाएँ, उसे GitHub Secrets (`KEYSTORE_B64`, `KEYSTORE_PASSWORD`) में रखें और रिपॉज़िटरी से `keystore.b64` हटा दें।
> - नया keystore इस्तेमाल करने पर पुराने APK वाले लोग अपडेट नहीं कर पाएँगे, उन्हें ऐप दोबारा इंस्टॉल करनी होगी।

## प्रोजेक्ट की बनावट

```
src/
  routes/        पेज (होम, सिलेबस, मॉक टेस्ट, आँकड़े, सेटिंग आदि)
  components/    ऐप के हिस्से (MCQ, मॉक टेस्ट, टाइपिंग आदि)
  lib/
    db/          IndexedDB और डेटा का बैकअप
    syllabus/    सिलेबस (syllabusData.ts) और परीक्षा योजना (examScheme.ts)
    content/     Supabase से MCQ और अध्ययन सामग्री का सिंक
    revision/    स्पेस्ड रिपीटिशन
    stats/       तैयारी का स्कोर
    notifications/  रिमाइंडर और परीक्षा काउंटडाउन
```

तकनीक: React 19, TanStack Router, Vite, Tailwind, IndexedDB (`idb`), Supabase, Capacitor।
